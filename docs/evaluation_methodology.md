# Evaluation Methodology

The framework separates evaluation into retrieval, generation, and operational dimensions.

Retrieval metrics:

- Context recall
- Context precision
- Hit@K
- Mean reciprocal rank
- NDCG

Generation metrics:

- Faithfulness
- Answer relevance
- Groundedness
- Hallucination score
- Semantic similarity

Operational metrics:

- Retrieval latency
- Generation latency
- Total pipeline latency
- Token usage
- Cost estimates
- Throughput
